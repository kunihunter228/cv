## Code Example

**Problem:** Peak array index from Codewars  
*Given an array of integers, return the index where the sum of elements to the left equals the sum of elements to the right. If no such index exists, return -1. If multiple indices exist, return the leftmost one.*

```javascript
function peak(arr) {
    for (let i = 1; i < arr.length - 1; i++) {
        let leftSum = arr.slice(0, i).reduce((acc, val) => acc + val, 0);
        let rightSum = arr.slice(i + 1).reduce((acc, val) => acc + val, 0);
        if (leftSum === rightSum) {
            return i;
        }
    }
    return -1;
}
